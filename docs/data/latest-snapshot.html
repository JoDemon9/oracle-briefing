Αγορές και τεχνολογία

Οι ΗΠΑ επεκτείνουν την απαίτηση άδειας εξαγωγής σε πέντε χώρες για προηγμένα τσιπ. Για προμηθευτές και πελάτες, το κρίσιμο είναι αν ο έλεγχος θα σταματά στον άμεσο αγοραστή ή θα εξετάζει και ποιος χρησιμοποιεί τελικά την υπολογιστική ισχύ. Στην Κύπρο, η πρόταση για κοινές χρεώσεις νερού ανά κυβικό μέτρο αλλάζει τη βάση υπολογισμού για τα νοικοκυριά. Χωρίς τον πίνακα χρεώσεων και τη σύγκρισή του με τα ισχύοντα τιμολόγια ανά επαρχία, δεν ξέρουμε ποιος θα πληρώσει περισσότερο. Τα επόμενα σημεία ελέγχου είναι οι αμερικανικοί όροι αδειοδότησης και η τελική πρόταση του Υπουργικού.
